Dual Band Reconfigurable Antenna Using PIN Diode

This project presents the design and simulation of a *dual-band reconfigurable microstrip antenna* using a *PIN diode* as the switching element. The antenna is designed to operate in two frequency bands for wireless communication applications.


## Project Overview

The antenna supports *frequency reconfiguration* by switching the PIN diode between ON and OFF states, enabling operation at two different resonant frequencies.

## Key Features:

- Dual-band operation using a PIN diode
- Reconfigurable structure (ON/OFF switching)
- Microstrip patch antenna design
- Simulated using **ANSYS HFSS**
- Includes S11 plots, VSWR plots, gain results, efficiency plots, and current distribution

## How Reconfiguration Works
The antenna incorporates a **PIN diode** at a strategic slot location.  
- **Diode ON → Frequency Band 1 active**  
- **Diode OFF → Frequency Band 2 active**

This enables switching between communication bands with minimal structural change.
